project_name: "Cloud-Native CI/CD & Infrastructure Platform on AWS EKS"
---

- Developed an end-to-end CI/CD pipeline to containerize and deploy a Python FastAPI microservice to AWS EKS (K8s v1.28) using Docker → ECR (scan-on-push), Terraform-based IaC, and Helm-driven releases across dev/staging/prod with autoscaling and environment isolation. [AWS EKS, Terraform, Helm, Docker]
- Enforced delivery controls including SonarQube quality gates, Trivy image scanning, manual approvals, and health-check–driven rollback using Kubernetes probes and resource limits to ensure secure, reliable deployments. [CI/CD, Kubernetes, SonarQube, Trivy]
