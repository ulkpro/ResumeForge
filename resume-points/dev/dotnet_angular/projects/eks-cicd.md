---
project_name: "Cloud-Native CI/CD & Infrastructure Platform on Azure AKS"
---

- Developed an end-to-end CI/CD pipeline via Azure DevOps to containerize and deploy an ASP.NET Core service to Azure Kubernetes Service (AKS) using Docker → ACR, Terraform-based IaC, and Helm-driven releases across dev/staging/prod with autoscaling. [Azure AKS, Terraform, Helm, Docker]
- Enforced delivery controls including SonarQube quality gates, Trivy image scanning, manual approvals, and health-check–driven rollback using Kubernetes probes and resource limits to ensure secure, reliable deployments. [CI/CD, Azure DevOps, Kubernetes]
