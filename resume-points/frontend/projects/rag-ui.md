project_name: "Internal Automation Dashboard (RAG UI)"

- Designed and built a multi-tenant React SPA with localized user-preferences, managing highly structured regulated workflow data visually for thousands of researchers and compliance officers. [React, RBAC UI]
- Integrated a document uploading engine using S3 multi-part strategies in the browser, featuring drag-and-drop utilities, real-time progress indicators, and comprehensive upload cancellation tracking. [File UI, XHR Progress]
- Integrated semantic search directly into the global app navigation via RAG APIs, giving users an instant overlay view mapping similar experiment parameters across prior historic documents natively. [Search Interfaces, UX]
