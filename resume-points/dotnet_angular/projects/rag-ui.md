project_name: "Internal Automation Dashboard (RAG UI)"
---

- Designed and built a multi-tenant Angular SPA with localized user-preferences, managing highly structured regulated workflow data visually for thousands of researchers and compliance officers. [Angular, RBAC UI]
- Integrated a document uploading engine using Azure Blob Storage block uploads in the browser, featuring drag-and-drop utilities, real-time progress indicators, and comprehensive upload cancellation tracking using RxJS. [Azure Blob, RxJS, File UI]
- Integrated semantic search directly into the global app navigation via Azure Cognitive Search APIs, giving users an instant overlay view mapping similar experiment parameters across prior historic documents natively. [Search Interfaces, UX, Azure]
